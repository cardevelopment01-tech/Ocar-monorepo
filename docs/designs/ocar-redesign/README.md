# Ocar rider redesign pack

Start with `PROMPTS.md`. Claude Code should read `DESIGN_BRIEF.md` first.

```
DESIGN_BRIEF.md      spec: screen map, tokens, components, behaviour, feature gaps, deltas from DESIGN.md
PROMPTS.md           copy-paste prompts, in order
screens/             the 9 design source files (*.dc.html) + canvas.json (board order and positions)
screenshots/         20 reference renders: every screen plus its expanded and sheet states
assets/              placeholder vehicle icons used in the design
```

Live canvas (private to the owner): https://claude.ai/artifact/AQT8tBhX1gwQZKVVmW4Q22

Screenshots are an approximate render of the .dc.html files and the .dc.html files are the authority on exact values. To retake exact screenshots, open the live canvas and capture each artboard.
